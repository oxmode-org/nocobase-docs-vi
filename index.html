NocoBase 3Quick start

Start your application with a conversation.

Install Skills, then work with your Agent to create your application, build features, and preview the results.

Compare NocoBase 2 and 3 →
Local environment: Node.js 24+ · pnpm 11
A Coding Agent that supports Skills, such as Claude Code or Codex
01

Install Skills

Install from your local terminal so your Agent knows how to create and develop NocoBase 3 applications.

Local terminal
npx skills@latest add nocobase/skills-v3 --skill '*' -g

Choose your Agent when prompted. After installation, start a new session to load the Skills.

What is installed? How do I update it?

Installs Skills globally from the dedicated NocoBase 3 repository, nocobase/skills-v3. Run the same command again to update them.

Once created, the application includes Skills that match its installed version.

02

Create and start your application

Open your Agent in an empty directory and ask it to create an application.

Send to your Agent
Create a NocoBase 3 App, start the local development environment, and tell me the application URL and how to sign in.

The Agent installs dependencies, configures the application, and starts it. Use SQLite for a first try, or specify another database.

Once the application is running, continue in the application directory and tell your Agent what you want to build.
