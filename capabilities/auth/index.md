# Authentication

Authentication identifies people accessing an application. After sign-in, a session identifies the current user. [Authorization](/nocobase-docs-vi/capabilities/authorization/index.md) determines which data and business actions that user can access.

## Available capabilities

| Capability                                                               | What it provides                                                                                                    |
| ------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------- |
| [Password authentication and accounts](/nocobase-docs-vi/capabilities/auth/password.md)                    | Username or email and password sign-in, registration controls, password requirements, recovery, and sign-in status. |
| [Accounts and sessions](/nocobase-docs-vi/capabilities/auth/password.md#company-managed-employee-accounts) | Create or disable employee accounts, sign out, and revoke existing sessions.                                        |
| [API keys](/nocobase-docs-vi/capabilities/auth/api-keys.md)                                                | Credentials for scripts and integrations, with expiry and revocation.                                               |
| [Additional sign-in methods](/nocobase-docs-vi/capabilities/auth/sign-in-methods.md)                       | Corporate identity providers, third-party accounts, and other authentication methods.                               |
| [Protected pages and APIs](/nocobase-docs-vi/capabilities/auth/protecting-access.md)                       | Public and authenticated pages, and current-user identity in APIs.                                                  |
| [Custom sign-in pages](/nocobase-docs-vi/capabilities/auth/login-pages.md)                                 | Company names, logos, backgrounds, layouts, and colors.                                                             |

## Where to start

Begin with [Password authentication and accounts](/nocobase-docs-vi/capabilities/auth/password.md) to learn how employees sign in and out and how accounts and sessions are managed. Explore API keys, additional sign-in methods, and protected access as needed, then [Customize the sign-in page](/nocobase-docs-vi/capabilities/auth/login-pages.md) to adapt its background, branding and layout.
