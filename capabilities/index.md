# Overview

NocoBase provides reusable capabilities for business applications. Describe your business goals to an AI Agent, which integrates authentication, authorization, data, processes, and collaboration into application-owned pages.

## Available capabilities

| Capability                                         | Purpose                                                                                                       |
| -------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| [Authentication](/nocobase-docs-vi/capabilities/auth/index.md)                 | Password and corporate sign-in, sessions, API keys, and branded sign-in pages.                                |
| [Data sources](/nocobase-docs-vi/capabilities/data-sources.md)                  | Application databases and existing external database connections.                                             |
| [Authorization](/nocobase-docs-vi/capabilities/authorization/index.md)          | Page, action, and record access, default access, sharing, restrictions, and inspection.                       |
| [Lifecycles](/nocobase-docs-vi/capabilities/workflow/index.md)                  | Business stages, human actions, external results, time limits, and transition history.                        |
| [Approval](/nocobase-docs-vi/capabilities/approval/index.md)                    | Multi-stage and multi-person approval rules and collaboration.                                                |
| [Task Center](/nocobase-docs-vi/capabilities/task-center.md)                    | Bring approvals, equipment collection and other personal work together with shared status filters and counts. |
| [Files](/nocobase-docs-vi/capabilities/file.md)                                 | Upload, association, preview, download, storage, and access control.                                          |
| [Notifications](/nocobase-docs-vi/capabilities/notification.md)                 | Business messages through inbox, email, or group channels, with delivery records.                             |
| [Email](/nocobase-docs-vi/capabilities/mail/index.md)                           | Personal mailboxes, correspondence, signatures, templates, and business integration.                          |
| [Scheduled tasks](/nocobase-docs-vi/capabilities/scheduler.md)                  | Reminders, reports, synchronization, execution records, and enablement controls.                              |
| [Languages](/nocobase-docs-vi/capabilities/i18n.md)                             | Language switching, translations, and application defaults.                                                   |
| [Themes](/nocobase-docs-vi/capabilities/theme.md)                               | Colors, typography, density, color modes, and custom presets.                                                 |
| [AI employees](/nocobase-docs-vi/capabilities/ai-employee/index.md)             | AI collaboration with models, tools, and business context.                                                    |
| [AI knowledge bases](/nocobase-docs-vi/capabilities/ai-knowledge-base/index.md) | Knowledge content and retrieval for AI.                                                                       |

Requirements differ by capability: external mail needs provider configuration, and complex approval needs its plugin. Application pages follow business needs rather than requiring a shared settings area.
