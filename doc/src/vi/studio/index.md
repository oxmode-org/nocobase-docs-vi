## Bắt đầu từ đâu

| Nếu bạn muốn | Hãy đọc |
| --- | --- |
| Hiểu về Studio | [Bắt đầu](intro/what-is-studio.md): những vấn đề Studio giải quyết, một yêu cầu đi từ ý tưởng đến phát hành ra sao, và đội Agent chia việc thế nào. |
| Thiết lập Studio cho nhóm | [Để Agent thiết lập Studio](setup/with-agent.md): đưa một prompt cho Agent của bạn, nó sẽ triển khai và cấu hình Studio, rồi hỏi có muốn chạy thử không. Các trang hướng dẫn từng bước có sẵn để tham khảo. |
| Dùng Studio lần đầu | [Tham gia nhóm](join/sign-in.md): nhận lời mời, đăng nhập, kết nối tài khoản Git của bạn và kết nối Agent của riêng bạn. |
| Nêu yêu cầu, theo dõi tiến độ và ra quyết định | [Dùng hằng ngày](use/raise-a-request.md): trao đổi yêu cầu với Agent, theo dõi các issue của bạn, trả lời câu hỏi của Agent và nghiệm thu kết quả. |
| Chăm sóc một dự án | [Quản lý dự án](project/settings.md): Skill, cơ sở tri thức, kiểm tra và review, bộ nhớ dự án, duyệt phát hành, tiến độ và mức sử dụng. |
| Quản trị Studio | [Quản trị hệ thống](admin/environments.md): môi trường triển khai, thành viên và vai trò, API key, thông báo, nâng cấp và sao lưu. |
| Tra cứu chi tiết | [Tham khảo](reference/statuses-and-permissions.md): trạng thái issue và phân quyền, các lệnh `nb-studio`, cấu hình và xử lý sự cố. |

Các trang có nhãn **EN** ở menu bên trái chưa được dịch và đang hiển thị bản tiếng Anh gốc.
