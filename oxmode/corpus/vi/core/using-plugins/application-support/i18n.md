## Năng lực

`@nocobase/app-plugin-i18n` cho phép chuyển ngôn ngữ khi ứng dụng đang chạy và đồng bộ tùy chọn với server. Framework quản lý tài nguyên dịch, namespace và cơ chế dịch. Ứng dụng cung cấp nội dung bản dịch và giao diện bộ chọn.

## Tình huống và ví dụ

### Tiếng Anh và tiếng Trung

1. Cung cấp tài nguyên `en-US` và `zh-CN` trên cả hai runtime.
2. Tích hợp bộ chọn hoặc dùng lại bộ chọn của template.
3. Chuyển ngôn ngữ rồi kiểm tra trang, nội dung plugin và lỗi từ server.
4. Tải lại để kiểm tra lựa chọn được giữ. Dùng `useSyncServerLocale()` để đồng bộ khi khởi động.

Endpoint là `GET /api/i18n/locales` và `PUT /api/i18n/locale`. Nếu server chưa hỗ trợ ngôn ngữ đã chọn, server dùng `en-US` và trả `fallback: true`, còn trình duyệt giữ lựa chọn. Khi lỗi kết nối, trình duyệt cũng giữ lựa chọn.

**Prompt phát triển** cho Coding Agent làm việc trong thư mục ứng dụng.

```text
Dùng plugin bản địa hóa để chuyển giữa tiếng Anh và tiếng Trung. Kiểm tra loader
tài nguyên client và server. Dùng lại useAppLocale và bộ chọn trong template.
Xử lý trạng thái đang chuyển và lỗi. Lưu lựa chọn trình duyệt rồi đồng bộ server
khi khởi động. Kiểm thử tải lại, ngôn ngữ server chưa hỗ trợ, lỗi kết nối và
nhiều tab. Giới hạn thay đổi ở giao diện và thông báo đã có bản dịch.
```

**Xong khi** nội dung ứng dụng và plugin đổi theo ngôn ngữ, lựa chọn được giữ sau tải lại, và giao diện xử lý đúng fallback của server hoặc lỗi kết nối.

## Nguyên tắc và triển khai

Dùng cấu trúc tệp thực tế của ứng dụng để tích hợp các phần sau.

| Phạm vi tích hợp | Thay đổi mã hoặc cấu hình | Thay đổi giao diện và hành vi |
| --- | --- | --- |
| Locale client và server | Thêm tài nguyên và loader | Danh sách ngôn ngữ phản ánh tài nguyên ứng dụng |
| Bộ chọn ở phần đầu trang | Dùng `useAppLocale` và xử lý chuyển đổi cùng lỗi | Cập nhật nội dung ứng dụng và plugin |
| Đồng bộ khi khởi động và báo lỗi | Dùng `useSyncServerLocale` và mã lý do ổn định | Đồng bộ tùy chọn server và giải thích khi phải dùng ngôn ngữ dự phòng |

### Nguồn ngôn ngữ

Đăng ký Client và Server. Danh sách ngôn ngữ lấy từ loader trong `client/locales/index.ts` và `server/locales/index.ts` của ứng dụng. Để thêm ngôn ngữ vào bộ chọn, thêm tài nguyên và loader cấp ứng dụng. Tài nguyên riêng của plugin chỉ bổ sung bản dịch cho plugin.

```yaml
i18n:
  defaultLocale: zh-CN
```

`APP_DEFAULT_LOCALE` ghi đè ngôn ngữ mặc định. Ngôn ngữ được chọn làm mặc định vẫn cần tài nguyên ứng dụng để xuất hiện trong bộ chọn.

### Tạo bộ chọn

Trong component nằm dưới `AppClientRoot`, dùng:

```tsx
import { useAppLocale } from '@nocobase/app-plugin-i18n/client';

const { locale, locales, setLocale, switching } = useAppLocale();
```

Hiển thị `locales`, gọi `setLocale(next)`, khóa thao tác đổi tiếp trong khi `switching` và xử lý khi lời gọi bị từ chối.

Khi chuyển, runtime nạp tài nguyên namespace, cập nhật giao diện cùng ngôn ngữ và hướng chữ HTML, lưu lựa chọn trình duyệt và đồng bộ server. Các plugin dùng chung runtime nên cập nhật theo.

## Ràng buộc phát triển với AI và kiểm chứng

### Ràng buộc riêng của plugin

- Lấy lựa chọn từ loader ứng dụng để bộ chọn phản ánh đúng tài nguyên.
- Xử lý lỗi `setLocale` và hiển thị đúng trạng thái khi server dùng ngôn ngữ dự phòng còn trình duyệt giữ lựa chọn.
- Kiểm tra văn bản thiếu, lựa chọn sau tải lại, các tab dùng chung phiên và lỗi server trong ứng dụng thật.

### Phạm vi

Các tab dùng chung phiên cũng dùng chung locale của server. Sau khi một tab chuyển ngôn ngữ, yêu cầu từ tab khác có thể dùng locale mới trước khi giao diện của tab đó cập nhật. Khi cần, dùng mã `error.reason` ổn định để hiển thị lỗi đã dịch.

Plugin tập trung vào chuyển ngôn ngữ và đồng bộ tùy chọn. Ứng dụng quản lý nội dung nghiệp vụ và quy trình quản trị bản dịch. Xem [Bản địa hóa client](../../developing-apps/localization.md) và [Bản địa hóa server](../../developing-apps/server-localization.md).
