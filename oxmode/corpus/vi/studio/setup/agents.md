Khi môi trường chạy đã trực tuyến, mở **Agent management › Agents**. Các mô hình phổ biến được tự động thêm và bật.

<a id="check-available-agents"></a>

## Kiểm tra agent khả dụng

Xác nhận **Where it runs** liệt kê môi trường chạy vừa kết nối. Mỗi cặp công cụ lập trình và mô hình tạo thành một agent.

![Các agent đang bật do môi trường chạy báo về](https://static-docs.nocobase.com/studio-en-setup-agents-20261030.png)

Giữ trách nhiệm và mức suy luận mặc định ở bước này. Agent điều phối dùng các mô tả trách nhiệm để phân công.

<a id="configure-the-lead-agent"></a>

## Cấu hình agent điều phối

1. Chọn **Settings** trong mục **Lead Agent** ở đầu trang.
2. Trong **First choice**, chọn agent khả dụng phù hợp với công việc suy luận và lập kế hoạch.
3. Nếu có mô hình khác khả dụng, có thể chọn mô hình đó trong **Fallback**.
4. Lưu và giữ các giá trị mặc định còn lại.

![Đặt mô hình chính và dự phòng cho agent điều phối](https://static-docs.nocobase.com/studio-en-setup-coordinator-20261030.png)

Hoàn tất khi nhóm có ít nhất một agent đang bật và lựa chọn chính của agent điều phối có môi trường chạy khả dụng.

Tiếp theo, [tạo dự án đầu tiên](new-project.md). Xem [Cấu hình agent](../configure/agents.md) để thêm mô hình hoặc điều chỉnh trách nhiệm và cách phân lịch.
